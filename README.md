# SuperGame5 — Cloud (GitHub Actions, Stockfish 19)

Облачная версия бота **SuperGame5**: играет на Lichess 24/7 **без вашего компьютера**,
движок — **Stockfish 19** (скачивается с официального релиза при каждом запуске,
в репозитории не хранится). Варианты (atomic, antichess, horde...) — на Fairy-Stockfish.

## Состав

```
SuperGame5-Cloud/
├── .github/
│   └── workflows/
│       ├── bot-runner.yml   ← запуск бота + скачивание SF19
│       └── keepalive.yml    ← проверка каждые 20 мин: жив ли бот
├── config.yml.template      ← конфиг бота (токен подставляется из секрета)
└── README.md
```

## Установка (15 минут)

### Шаг 1. Создайте репозиторий
1. Зайдите на github.com → **New repository**
2. Имя: например `supergame5-cloud`
3. **Public** (важно: у приватных репо лимит 2000 минут Actions/месяц — не хватит на 24/7)
4. Не добавляйте README при создании → **Create repository**

### Шаг 2. Загрузите файлы
На странице пустого репо нажмите **uploading an existing file** и перетащите
**всё содержимое** папки SuperGame5-Cloud (папку `.github` тоже — она скрытая,
в проводнике включите отображение скрытых файлов).

Структура в репо должна получиться такой:
```
.github/workflows/bot-runner.yml
.github/workflows/keepalive.yml
config.yml.template
README.md
```
Нажмите **Commit changes**.

### Шаг 3. Добавьте токен Lichess
1. Settings → **Secrets and variables** → **Actions**
2. **New repository secret**
3. Name: `LICHESS_TOKEN`
4. Secret: токен вашего **бот-аккаунта** (с правом `bot:play`)
5. **Add secret**

### Шаг 4. Запуск
1. Вкладка **Actions** → слева **Lichess Bot Runner** (если написано Disabled — включите кнопкой Enable)
2. **Run workflow** → **Run workflow**
3. Через 2-3 минуты бот онлайн! В логе шага "Download Stockfish 19" будет строка
   `id name Stockfish 19` — доказательство, что работает именно 19-я 🙂

## Как это работает

- Джоба живёт **5 ч 40 мин**, затем завершается — лимит GitHub (6 ч)
- **Keepalive** каждые 20 минут проверяет: если бот не запущен — запускает заново
- Простой между перезапусками: **1-3 минуты**, редко до 20
- Партии сохраняются в артефакты: Actions → запуск → Artifacts → `game-records-...`
- Движки (SF19 + Fairy-Stockfish) скачиваются при каждом старте — репо остаётся лёгким

## Важно ⚠️

1. **Не запускайте локальный SuperGame5 и облачный одновременно** под одним
   аккаунтом — Lichess не любит две сессии бота. Либо остановите локального,
   либо создайте отдельный бот-аккаунт для облака.
2. **Никогда не коммитьте настоящий токен** — только через Secrets.
   Ваш локальный `config.yml` содержит токен — не загружайте его на GitHub!
3. GitHub Actions формально не предназначен для хостинга 24/7 — есть
   небольшой риск ограничения аккаунта. Репо должно быть public, не создавайте
   десятки таких ботов.
4. На раннере GitHub 4 ядра (у вас дома 16 потоков), поэтому облачный бот чуть
   слабее локального — но это всё ещё Stockfish 19 🙂
